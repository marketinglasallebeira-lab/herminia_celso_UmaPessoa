# Convite de Casamento — Hermínia & Celso

Página web estática, pronta para publicação no GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo: `herminia-celso`).
2. Carregue **todos os ficheiros e pastas deste pacote** para a raiz do repositório:
   - `index.html`
   - `.nojekyll`
   - `assets/envelope-hc.webp`
   - `assets/convite-herminia-celso.webp`
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Seleccione a branch `main` e a pasta `/ (root)`; clique em **Save**.
6. Aguarde a publicação. O GitHub apresentará o endereço público em **Settings → Pages**.

## Funcionalidades

- O envelope H&C é a primeira página; ao clicar, abre o convite.
- O botão **Confirmar presença** abre `https://convitin.com.br/herminia-celso/`.
- O botão de regresso permite voltar ao envelope.
- Layout responsivo para telemóveis e computadores.

Não é necessário instalar dependências nem executar um processo de build.
